# External Research Notes for DET 7 Beyond Consciousness Engineering Applications

## Source findings

| Source | URL | Key finding for DET deep dive |
|---|---|---|
| Torzoni et al., **Active Digital Twins via Active Inference** | https://arxiv.org/html/2506.14453v1 | Digital twins are described as real-time virtual representations that synchronize with physical systems through sensor data, support what-if simulation, and enable predictive decision-making. The active digital twin proposal explicitly adds closed-loop perception-action, Bayesian state inference, active exploration, and resilience-oriented maintenance. This maps well to DET’s identity/observer split: a digital twin can preserve identity-like model continuity, while an active twin adds observer-like self-monitoring and local action selection. |
| Flammini, **Digital twins as run-time predictive models for the resilience of cyber-physical systems** | https://royalsocietypublishing.org/doi/10.1098/rsta.2020.0369 | Digital twins are framed as run-time predictive models for cyber-physical-system resilience, self-monitoring, self-diagnosis, and self-healing. The article explicitly links digital twins, autonomic computing, MAPE-K feedback loops, dependability, safety, security, and trustworthy autonomy. This supports DET engineering applications in debt-aware maintenance, self-healing controllers, and safety certification readouts. |
| Ramirez, Agrawal, and Thompson, **An Approach Integrating MBSE, IoT, and Digital Twin for Electric Unmanned Autonomous Vehicles** | https://www.mdpi.com/2079-8954/13/2/73 | The paper demonstrates transformation of descriptive SysML/MBSE models into digital-twin representations synchronized with physical autonomous vehicles via real-time data, SITL, and HITL. This supports a practical DET application path: encode DET variables as live MBSE/digital-twin state observables and use them for model validation, testing, and design-loop control. |
| Johansson and Lundberg, **No robot is an island** | https://www.tandfonline.com/doi/full/10.1080/1463922X.2024.2401168 | Autonomous systems are self-sufficient only within design boundaries; resilience requires anticipation, monitoring, control, recovery, learning, self-monitoring, core values, resource context, and interoperability. This maps strongly onto DET boundary participation: higher-level agency is not isolated self-sufficiency but lawful participation in a resource/context boundary. |

## Application synthesis

The external literature supports four practical application tracks for the attached DET paper. First, **debt-aware digital twins** can treat `q`, coherence, presence, and identity persistence as live observables for predictive maintenance. Second, **resilient autonomy** can use the DET layer hierarchy to separate basic actuation capacity from persistent identity, self-monitoring, and boundary-mediated recovery. Third, **MBSE/HIL validation** can use the DET metrics as state variables in design-time and run-time system models. Fourth, **human-machine and socio-technical systems** can interpret boundary participation not as supernatural intervention but as resource-context coupling, interoperability, and recovery pathways that remain local, testable, and non-coercive.
