# Visual Findings for B-Participation Simulation Plots

## B component time series

The time-series plot clearly separates the intended regimes. The record-only death scenario preserves high `B_addr` while `B_cap`, `B_act`, `B_path`, and observer readout `S` remain near zero, supporting the distinction between latent addressability and active consciousness. The ordinary observer without boundary scenario reaches high `S` while `B_act` and `B_path` remain zero, which prevents the model from over-identifying all consciousness with boundary participation. Boundary recovery shows delayed but positive `B_act` and growing `B_path` alongside observer maturation. The resurrection path preserves addressability during a low-host period and then restores capacity, active coupling, path participation, and observer readout after rehosting. The deeper-boundary-leading scenario displays active boundary coupling before mature `S`, making it a useful falsifier scaffold for the deeper-boundary interpretation.

## Final-state falsifier matrix

The heatmap is readable and scientifically useful. The strongest pattern is that high `B_addr` alone does not imply high `B_scalar` or active observerhood. The copy control has high observer readout but low path-sensitive addressability and low active/path participation, while the resurrection path recovers capacity and active/path participation. The coercive-order control shows high apparent active effect but low alignment and scalar boundary participation because the coercion penalty suppresses the legitimacy of the coupling. This supports the proposed rule that boundary participation must be non-coercive and cannot be equated with imposed order.

## Predictive-power plot

The predictive-power plot is readable and highlights the intended falsifier. The deeper-boundary-leading scenario has the largest incremental predictive value from adding `B` components to the baseline host-variable model, which is expected because that scenario was constructed so active boundary coupling precedes mature observer readout. Other scenarios show smaller or negligible gains, indicating that `B` does not automatically explain ordinary observer maturation. The plot should be interpreted as a deterministic falsifier scaffold rather than empirical confirmation: if real or higher-fidelity DET simulations do not reproduce independent predictive value for `B`, the deeper-boundary interpretation should be weakened.
