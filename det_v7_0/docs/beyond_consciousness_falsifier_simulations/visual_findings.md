The death/resurrection edge-case plot cleanly separates four claims that should not be conflated. First, `death_frozen_record` drives presence/participation essentially to zero while retaining a nonzero record-integrity proxy. This supports the formal distinction that record persistence is not by itself active consciousness. Second, `active_spirit_channel` retains a small but nonzero presence only because the model explicitly declares a spirit-channel parameter. Third, `resurrection_rehost` shows active participation and observer readout recovering after rehosting from the preserved record. Fourth, `copy_without_path` can regain active-state features but receives a low path-overlap factor, illustrating why snapshot resemblance alone should not be treated as identity continuity.

The utopic-boundary plot verifies the v7-safe distinction between high utopic-regime capacity and present lawful coupling. Both scenarios have a growing utopic-regime capacity, but only `utopic_connected_noncoercive` has nonzero `kappa`. Consequently, only the connected scenario reduces the damage readout, while the disconnected scenario leaves the ordinary regime unchanged. The direct agency-write deviation remains identically zero, supporting the non-coercion constraint: the boundary regime may alter recovery conditions through declared channels, but it does not directly write agency.

The continuity-control bar chart makes the copy-control requirement explicit. `copy_without_path` has a nonzero snapshot similarity but almost no path-sensitive identity score, because the simulation assigns no lawful continuity channel from the pre-death record into the copied host. This is a key scientific safeguard: any resurrection or persistence model must include an explicit continuity path and cannot rely solely on resemblance, reconstruction fidelity, or narrative equivalence.
